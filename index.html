# 📚 TSSR Quiz — Déploiement automatique GitHub → Firebase ## Structure du projet ``` tssr-quiz/ ├── public/ │ └── index.html ← ton quiz (sans clés Firebase) ├── .github/ │ └── workflows/ │ └── deploy.yml ← pipeline de déploiement automatique ├── firebase.json ← config Firebase Hosting ├── .gitignore └── README.md ``` ## Comment ça marche ``` Tu modifies index.html → git push → GitHub Actions injecte les clés → Firebase se met à jour ``` Les clés Firebase ne sont **jamais** dans le code — elles sont stockées dans les **Secrets GitHub**. --- ## 🚀 Mise en place (une seule fois) ### Étape 1 — Créer le repo GitHub ```bash git init git add . git commit -m "initial commit" git branch -M main git remote add origin https://github.com/TON_USERNAME/tssr-quiz.git git push -u origin main ``` ### Étape 2 — Créer le Service Account Firebase 1. Va sur [console.firebase.google.com](https://console.firebase.google.com) → ton projet 2. ⚙️ **Project Settings** → onglet **Service accounts** 3. Clique **Generate new private key** → télécharge le fichier JSON 4. Copie **tout le contenu** de ce fichier JSON (tu en auras besoin à l'étape 3) ### Étape 3 — Ajouter les Secrets dans GitHub Dans ton repo GitHub → **Settings** → **Secrets and variables** → **Actions** → **New repository secret** Ajoute ces 7 secrets : | Nom du secret | Valeur | |---|---| | `FIREBASE_API_KEY` | `AIzaSyBXMDEKxQ2HP5d4lxSx0IpaDEIjrhAFSEE` | | `FIREBASE_AUTH_DOMAIN` | `tssrquizz-2744f.firebaseapp.com` | | `FIREBASE_PROJECT_ID` | `tssrquizz-2744f` | | `FIREBASE_STORAGE_BUCKET` | `tssrquizz-2744f.firebasestorage.app` | | `FIREBASE_MESSAGING_SENDER_ID` | `968867578298` | | `FIREBASE_APP_ID` | `1:968867578298:web:b67e5854522788a8d1dd83` | | `FIREBASE_SERVICE_ACCOUNT` | *(colle tout le contenu du fichier JSON de l'étape 2)* | ### Étape 4 — Autoriser GitHub Actions sur Firebase ```bash firebase init hosting:github # → repo : TON_USERNAME/tssr-quiz # → set up workflow : No (on a déjà deploy.yml) ``` --- ## ✏️ Workflow quotidien (ajouter des questions, changer le thème...) ```bash # 1. Modifie public/index.html (questions, styles, features...) # 2. Commit & push git add public/index.html git commit -m "ajout questions VLANs" git push # → GitHub Actions se déclenche automatiquement (~1 min) # → Firebase est mis à jour ``` Tu peux suivre le déploiement dans l'onglet **Actions** de ton repo GitHub. --- ## 🔥 Règles Firestore (si pas encore fait) Dans Firebase Console → **Firestore → Rules** : ``` rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } } } ``` → **Publish**
